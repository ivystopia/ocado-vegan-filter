# Egg-alternative parser impact

Read-only SQLite comparison finds two all-known products, both stored-current, matching the narrow alternative/substitute to/for egg(s) grammar. V32 routed both to semantic assessment because that referenced animal token was treated as content. V33 removes only the referenced egg token, preserving adjacent and nested composition. The complete records and before/after rule decisions are in impact.json. Existing supported whole-product manufacturer claims can now qualify under the common gate. No canonical row was written.

Safety regressions cover the actual mayonnaise description, separate Eggs/Milk/Gelatine ingredients, contradictory official tags, nested gelatine, egg whites, a later animal declaration and a manufactured product without established composition or claim. The repair does not infer vegan suitability from an alternative label alone.
